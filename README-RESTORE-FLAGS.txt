MITRON MARKET - RESTORED ORIGINAL MODI-STYLE FLAGS

SETUP
1. Extract this ZIP.
2. Open the maankibaat-main folder in Terminal / Command Prompt.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000

This archive intentionally excludes node_modules. package.json and package-lock.json are included.

Six flags are accepted by the single /submit-flag form. The original five MODI-style flags have been restored, and the new 2FA challenge uses MODI{Doosra_Darwaza_Khula}.
